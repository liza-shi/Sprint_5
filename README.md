# Sprint_5
В проекте UI-автотесты для Stellar Burgers.

Адрес: https://stellarburgers.education-services.ru

Ниже перечислено, что проверяем.

# Регистрацию:
- успешная регистрация;
- ошибка при пароле короче шести символов.

# Вход:
- вход по кнопке «Войти в аккаунт»;
- вход через «Личный кабинет»;
- вход через форму регистрации;
- вход через форму восстановления пароля.

# Личный кабинет:
- переход в личный кабинет;
- переход в конструктор;
- переход по логотипу;
- выход из аккаунта.

# Конструктор:
- переход к разделу «Булки»;
- переход к разделу «Соусы»;
- переход к разделу «Начинки».

Примененные технологии:
- Python 3;
- Selenium WebDriver;
- pytest;
- Google Chrome.

Для установки: 
1. Создать виртуальное окружение:
bash
python3 -m venv .venv

2юАктивировать окружение:
bash
source .venv/bin/activate

3. Установить зависимости:
bash
python -m pip install -r requirements.txt


Для запуска:
bash
python -m pytest -v


После завершения каждого теста браузер закрывается командой:
python
driver.quit()
